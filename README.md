# 🧩 Práctica 3: Continuous Integration [1B]

## 📘 Descripción del proyecto
Este proyecto corresponde a la **Práctica 3 de la materia de Integración Continua**, cuyo objetivo es aplicar herramientas y metodologías DevOps para automatizar el proceso de desarrollo de software.  

El proyecto consiste en una aplicación Java que permite **visualizar operaciones matemáticas desde una terminal**, desarrollada con **Maven**, e integrada con **JUnit** y **Mockito** para la realización de pruebas unitarias.

> **Historia de usuario:**  
> “Como usuario deseo visualizar operaciones matemáticas desde una Terminal”.

---

## 🧱 Estructura del proyecto
El proyecto fue creado con **Maven** y contiene las siguientes secciones principales:

- `src/main/java`: Código fuente de la aplicación.  
- `src/test/java`: Pruebas unitarias con JUnit y Mockito.  
- `pom.xml`: Archivo de configuración de Maven (dependencias y plugins).  

---

## ⚙️ Tecnologías utilizadas
- **Java 17**  
- **Apache Maven**  
- **JUnit 5**  
- **Mockito**  
- **Git & GitHub**  
- **Jenkins**
